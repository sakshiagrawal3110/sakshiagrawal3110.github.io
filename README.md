# Portfolio Website

A single-page portfolio site built in plain HTML with inline CSS and minimal JavaScript. The page is designed for a senior UX/Product designer with a clean, editorial layout and subtle motion.

## Overview

- File: `portfolio.html`
- Content: hero, work, approach, research, design system, about, and contact sections
- Styling: embedded CSS inside the HTML document
- Interaction: smooth scrolling, hover states, and a scroll reveal animation
- No external build tools required

## Key Sections

1. **Navigation**
   - Fixed top nav with links to page sections and a contact CTA

2. **Hero**
   - Headline, descriptive copy, CTA buttons, and an expertise progress card

3. **Marquee**
   - Repeating skill and service highlights in a horizontal marquee loop

4. **Work**
   - Selected project cards with short case study summaries and tags

5. **Approach**
   - Design philosophy cards for research, systems, and AI-native design

6. **Research**
   - Research case studies with details on type, year, and outcomes

7. **Design System**
   - Token showcase including colors, typography, components, spacing, and radius

8. **About**
   - Bio, experience stats, and skill tags

9. **Contact**
   - Contact links and a UI-only contact form layout

10. **Footer**
    - Simple copyright and location line

## Usage

- Open `portfolio.html` in a browser to view the portfolio page.
- No server or dependencies needed.

## Notes

- Uses Google Fonts (`DM Mono`, `Syne`, `Instrument Serif`)
- Includes a vanilla JS intersection observer for reveal animations
- Designed to be easily customizable by updating text, colors, or section content
